It is one developer's working tool, opened up. There is no support obligation, no uptime commitment, and no promise that any particular version will keep working.

What you are responsible for

Installing software on machines you are allowed to install software on. Remote Visio installs its own bundled audio driver (a Core Audio HAL plug-in) into /Library/Audio/Plug-Ins/HAL through make install-driver, which asks for your admin password; make uninstall-driver removes it.

Also: whatever you say into it. A microphone that reaches another building is still a microphone — know which applications on the far end are listening.

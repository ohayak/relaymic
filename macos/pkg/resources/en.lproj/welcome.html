Remote Visio turns the microphone of any device's browser into a microphone on this Mac, and sends this Mac's sound back.

This installer will:

  • Add the Remote Visio virtual audio device (a Core Audio driver in /Library/Audio/Plug-Ins/HAL) and restart the audio system, which pauses sound for about a second.
  • Install RemoteVisio.app in Applications: a menu-bar app that runs the receiver, then start it and set it to open at login.
  • Add a virtual camera, Remote Visio Camera, that shows the remote device's camera in this Mac's video apps.

Nothing else is needed on this Mac. The app is self-contained.

Remote Visio turns the microphone and camera of any device's browser into a microphone and camera for this Mac's meetings, and sends the meeting's sound back to that device.

This installer will:

  • Install RemoteVisio.app in Applications: a menu-bar app that runs the receiver, then start it and set it to open at login.
  • Add a virtual camera, Remote Visio Camera, that shows the remote device's camera in this Mac's video apps.
  • Remove the Remote Visio virtual audio device that earlier versions installed, if this Mac has it, and then restart the audio system, which pauses sound for about a second.

The microphone and speaker come from the Remote Visio browser extension, for meetings in Chrome, Edge, Brave, Arc and other Chromium browsers: the app's menu adds it once the installation is done. Nothing else is needed on this Mac.

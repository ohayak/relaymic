Remote Visio convierte el micrófono del navegador de cualquier dispositivo en un micrófono de este Mac, y devuelve el sonido de este Mac.

Este instalador:

  • Añade el dispositivo de audio virtual Remote Visio (un controlador de Core Audio en /Library/Audio/Plug-Ins/HAL) y reinicia el sistema de audio, lo que corta el sonido durante un segundo.
  • Instala RemoteVisio.app en Aplicaciones: una app de la barra de menús que ejecuta el receptor; luego la inicia y la configura para abrirse al iniciar sesión.

No hace falta nada más en este Mac. La app es autónoma.

Remote Visio 已经在菜单栏里运行。

  1. macOS 可能会请求 Remote Visio 的「系统声音录制」和「麦克风」权限。两个都允许；不允许的话，对方从这台 Mac 只能听到静音。
  2. macOS 询问摄像头扩展时，请允许它：系统设置 > 通用 > 登录项与扩展 > 相机扩展。之后 Remote Visio Camera 会作为一个摄像头出现在视频应用里。
  3. 在需要麦克风的应用里（Zoom、听写、任何应用），把输入设备选成 Remote Visio。
  4. 点菜单栏里的 Remote Visio 图标复制地址，在你要说话的那台设备的浏览器里打开它。第一次浏览器会警告自签证书，继续前往即可。

以后要移除 Remote Visio，在菜单栏菜单里选 卸载 Remote Visio…，或者在终端里运行 /Applications/RemoteVisio.app/Contents/Resources/uninstall.sh。
